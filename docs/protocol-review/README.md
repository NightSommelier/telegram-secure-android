# Protocol review package

This is the sole first-cycle deliverable. It contains no implementation and does not authorize one.

- `../secure-overlay-protocol-v1.md` — normative wire, handshake, ratchet boundary and failure behavior.
- `test-vectors.json` — machine-readable canonical, KDF and envelope fixtures.
- `negative-fixtures.json` — mandatory reject cases.
- `OPEN-ISSUES.md` — items preventing approval.
- `REVIEW-DECISION.md` — starts as changes required.
- `REVIEW-CHECKLIST.md` — review scope and required recorded decisions.
- `REVIEW-HANDOFF.md` — exact artifact handoff and checksum procedure.
- `REVIEW-ARTIFACTS.sha256` — SHA-256 manifest for this exact review scope.
- `FIXTURE-COVERAGE.md` — present evidence and vectors still required before approval.
- `REVIEW-REQUEST.md` — the review scope and required written decision.

Hex values are lower-case. Public test private values MUST NOT be imported by an application.
