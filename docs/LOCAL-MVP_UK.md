# Локальний MVP: Telegram Fork-Secure

> [!NOTE]
> [The English version of this documentation is available in LOCAL-MVP.md](LOCAL-MVP.md).

Цей документ описує процес налаштування, збірки та тестування **Telegram Fork-Secure** на реальних пристроях Android.

Fork-Secure додає наскрізне шифрування (E2EE) для звичайних 1:1 хмарних чатів та окремий захищений режим для «Збережених повідомлень» (Saved Messages). Нативні Secret Chats Telegram, канали та групові чати залишаються незмінними.

Криптографічний шар залишається у процесі аудиту ([`CHANGES REQUIRED`](protocol-review/REVIEW-DECISION.md)). Не розглядайте цей білд як повністю сертифікований захищений месенджер.

---

## Одноразове налаштування

1. **Отримання облікових даних Telegram API**:
   Створіть додаток на [my.telegram.org/apps](https://my.telegram.org/apps), щоб отримати валідні `api_id` та `api_hash`.
2. **Конфігурація середовища**:
   Скопіюйте `local.properties.example` у `local.properties`:
   ```properties
   TELEGRAM_API_ID=123456
   TELEGRAM_API_HASH=abcdef0123456789abcdef0123456789
   sdk.dir=/шлях/до/android-sdk
   ```
3. **Android SDK та інструменти**:
   Потрібні JDK 21, Android SDK платформи 35/36, build-tools 35.0.0/36.0.0, NDK `27.2.12479018` та CMake `3.22.1`. Також можна використати готове оточення Nix (`nix-shell`).

Перевірте коректність середовища перед збіркою:
```bash
./scripts/check-local-mvp.sh
```

## Локальна збірка та встановлення

### Швидкий цикл розробки (ARM64 Debug Build)

Збірка та встановлення на підключений телефон через ADB:
```bash
./scripts/build-local-mvp.sh
./scripts/install-local-mvp.sh <серійний_номер_пристрою>
```

Або запуск комплексного скрипта (збірка, встановлення та старт додатка):
```bash
./scripts/run-local-mvp.sh <серійний_номер_пристрою>
```

Debug APK використовує пакет `ua.securechat.telegram` та підписується стандартним debug-ключем, що дозволяє працювати паралельно з офіційним додатком Telegram.

### Релізний підпис

Для збірки релізного пакунка з власним ключем:
```bash
./scripts/create-release-keystore.sh
```
Це створить каталог `keystore/` та файл `signing.properties`. Потім запустіть збірку релізного APK:
```bash
./gradlew :TMessagesProj_App:assembleAfatRelease --console=plain
```

## Підтримувані та перевірені можливості (база Telegram 12.10.5)

- **Текст та форматування**: Зашифрований UTF-8 текст, сутності, підписи, клієнтське розпізнавання посилань, безпечне очищення цитат у відповідях.
- **Медіафайли**: Фото, відео, голосові повідомлення, круглі відеонотатки, аудіо/музика, довільні файли та стікери з відтворенням безпосередньо з розшифрованого кешу.
- **Контакти**: Зашифрований кодек `TYPE_CONTACT`; незашифровані vCard-дані Telegram очищуються.
- **Геопозиція**: Зашифрований кодек `TYPE_GEO_LOCATION` із секретним режимом прев'ю, що блокує зовнішні запити до картографічних сервісів.
- **Дистанційне видалення**: Криптографічно підписані пакети `TYPE_CONTROL_DELETE`, що видаляють шифротекст, локальний кеш та файли на диску обох учасників.
- **Безпечне пересилання**: Локальне розшифрування та повторне шифрування під сесію отримувача зі збереженням звукових хвиль та параметрів.
- **Захист від спуфінгу посилань (`SecureLinkGuard`)**: Фільтрація Punycode, IDN-омогліфів, BiDi-символів та спуфінгу authority з обов'язковим діалогом підтвердження.
- **Захист екрана**: Примусовий `FLAG_SECURE` для вікон чату, профілю та переглядача медіа; експорт до галереї та поширення файлів заблоковані.
