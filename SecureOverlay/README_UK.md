# SecureOverlay

> [!NOTE]
> [The English version of this documentation is available in README.md](README.md).

Ця бібліотека Android є ізольованою межею функціональності безпеки Telegram Secure.

Вона навмисно не має прямих залежностей від `TMessagesProj`, коду TDLib/MTProto чи транспорту повідомлень Telegram. Бібліотека використовує офіційний артефакт `libsignal` для Android виключно всередині цього модуля; код основного додатку взаємодіє з нею через вузький адаптер.

Бібліотека ліцензована на умовах AGPLv3. Кожен, хто отримує збірку з цим модулем, повинен також отримати відповідний вихідний код та ліцензійні повідомлення. Цей проєкт є дослідницьким MVP, а не фінальним комерційним релізом.
